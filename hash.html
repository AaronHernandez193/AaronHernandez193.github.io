Búsqueda por Funciones HASH

La búsqueda mediante tablas Hash transforma la clave de búsqueda a través de una fórmula matemática para calcular exactamente la posición (índice) donde se encuentra el dato en la memoria. Es el método de acceso más rápido que existe.

Características:

  • Complejidad de Tiempo: O(1) en el caso promedio. El tiempo de búsqueda es inmediato, no importa si hay 10 o 10 millones de datos.
  • Colisiones: Ocurren cuando la fórmula da el mismo resultado para dos datos distintos. El sistema debe saber manejar estos "choques".
Contexto en Sistemas Operativos (Tanenbaum): Según Andrew S. Tanenbaum en "Sistemas Operativos Modernos", los equipos de 64 bits se enfrentaron a un problema: las tablas de páginas convencionales para la memoria virtual se volvieron inmensas.

La solución fue implementar Tablas de Páginas Invertidas combinadas con funciones Hash. El sistema operativo aplica una función hash a la página virtual solicitada para encontrar rápidamente en qué marco de la memoria RAM (memoria física) está ubicada, reduciendo una búsqueda enorme a un solo paso O(1).
