¿Qué es la Búsqueda Secuencial (Lineal)?

La búsqueda secuencial es el método más sencillo y directo para encontrar un elemento en un conjunto de datos. Consiste en recorrer la estructura (como un arreglo o una lista) elemento por elemento, desde el principio hasta el final, comparando cada uno con el valor que se desea buscar.

Características:

  • Complejidad de Tiempo: O(n) en el peor de los casos, donde n es el número total de elementos.
  • Requisito: No requiere que los datos estén ordenados.
  • Ventaja: Es extremadamente fácil de implementar y es la única opción para datos no estructurados.
Contexto en Sistemas Operativos: En sistemas de archivos simples o heredados (como las primeras versiones de FAT), cuando el OS necesita encontrar un archivo dentro de un directorio, realiza una búsqueda secuencial leyendo las entradas de la tabla del directorio una por una hasta encontrar el nombre del archivo solicitado.
